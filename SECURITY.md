# Security Policy

Please do not publish exploitable issues in a public issue before a fix is available. Report suspected duplication, arbitrary entity deletion, event injection, or webhook exposure privately to the repository owner **pichirin_cb**.

Community and private contact: [CB Studios Discord](https://discord.gg/hsx6AvBg5s). Documentation is available at [docs.pichirincb.com](https://docs.pichirincb.com/#/).

Include the resource version, server artifact version, reproduction steps, relevant console output and any conflicting resources. Never include live Discord webhook tokens, database credentials or player personal data.

If a Discord webhook is ever committed or shared, delete/regenerate it in Discord immediately. Removing it from the latest file does not invalidate the leaked token and does not remove it from existing Git history.
