# Contributing

Thank you for helping improve Fortuna Hunting Wagon.

Read the [documentation](https://docs.pichirincb.com/#/) and join the [CB Studios Discord](https://discord.gg/hsx6AvBg5s) for community support.

1. Open an issue describing the bug or proposed behavior before a large change.
2. Keep all cargo mutations server-authoritative and validate entity ownership context, model, type, distance and capacity.
3. Do not introduce mandatory framework or UI dependencies without discussion.
4. Update all six locale files when adding user-facing or Discord text.
5. Never commit webhook URLs, credentials, player identifiers or production logs.
6. Test storing, retrieving, failed spawning, disconnect rollback, full capacity and wagon deletion.
7. Update `README.md` and `CHANGELOG.md` for user-visible changes.

Contributions are accepted under GPL-3.0-or-later and must preserve the copyright and attribution notices for **pichirin_cb**.
